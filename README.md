# RemoteLink — المرحلة 1

الأساس + الاقتران + الاتصال المشفّر بين جوالين (بدون إنترنت).

## البناء (GitHub Actions)
1. أنشئ مستودعًا جديدًا وارفع محتويات هذا المجلد.
2. تبويب Actions ← Android Build ← Run workflow.
3. نزّل الـ artifact باسم `RemoteLink-apk` وثبّت `app-debug.apk` على الجوالين.
(التوقيع الاختياري: أضف أسرار KEYSTORE_BASE64 و STORE_PASSWORD و KEY_ALIAS و KEY_PASSWORD.)

## اختبار المرحلة 1
1. الجوالان على نفس شبكة الراوتر (حتى لو بلا إنترنت).
2. جوال أ: «هذا الجوال هو المتحكَّم به» ← تشغيل الاستقبال ← إقران جهاز جديد.
3. جوال ب: «هذا الجوال هو المتحكِّم» ← مسح رمز QR ← أدخل الرقم السري ← تظهر جلسة الاتصال.
4. قطع Wi-Fi لثوانٍ وإعادته: يجب أن تظهر «إعادة المحاولة» ثم يعود الاتصال تلقائيًا.
5. جرّب أيضًا «عنوان يدوي» بإدخال IP جوال أ.
